# OpenCode V2 port

This package targets OpenCode 2.x. The V2 server entrypoint is `server.js`.

Install Node.js 22+ and run:

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run build
npm run test:v2
```

Add this checkout directory to `plugins` in `opencode.json`. For CLI toast
notifications, add the `tui` directory to `plugins` in `cli.json`.

V1 source remains for shared behavior and regression tests. V2 loads the
adapter, not the legacy hook factory.

The adapter forces HTTP and routes OpenAI OAuth response requests through an
authenticated loopback proxy. API-key connections bypass rotation. Account files
and rotation logic retain their upstream locations. CLI notifications require
the companion TUI entrypoint.
